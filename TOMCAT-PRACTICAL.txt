definition: The tomcat-users.xml file is used to configure user accounts and roles for the built-in Tomcat Manager and other web applications. It defines which users have access to specific features in Apache Tomcat, such as managing deployed applications or monitoring the server.

>> Changing the default port of Apache Tomcat on CentOS 9 involves modifying its configuration file. Here’s how you can do it step by step:
=============================================================================================================================================

	# cd /etc/tomcat/
	# vim server.xml

 > Lets Change  the default port of Apache Tomcat on CentOS 9. 
   Ensure the new port is not already in use by another service. You can check with:

	# netstat -tuln | grep <port>


 > Change the port attribute to your desired port number. For example, to change it to port 9090:

	<Connector port="9090" protocol="HTTP/1.1" 
           connectionTimeout="20000"
           redirectPort="8443" />

	:wq!

 > update the firewall rule :
	
	# firewall-cmd --permanent --add-port=9090/tcp ; firewall-cmd --reload : firewall-cmd --list-all
	
	# systemctl restart tomcat

 > Test the new port by accessing your application in a browser or with curl:

	# http://<your-server-ip>:9090
